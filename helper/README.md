# Unbubble (helper)

The free, open-source helper behind [thegreymirror.com/export](https://thegreymirror.com/export). It exports iMessages from an iPhone over USB without a full backup, and serves the same export interface as a standalone app.

See the [project README](https://github.com/justlayme/unbubble#readme) for how it works, development setup and releases. Licensed GPL-3.0-or-later.
