# Unbubble helper source

For the free iPhone-only iMessage exporter, use the [Unbubble iPhone app](https://apps.apple.com/us/app/unbubble-imessage-exporter/id6829522001) and the [official export guide](https://thegreymirror.com/grey-mirror/unbubble). Export PDF or CSV directly on your iPhone, with no Mac or PC required, subscription, account or paid export unlock.

This directory contains the separate legacy helper implementation for developers maintaining existing integrations. It is not a requirement for the iPhone app. See the [main project README](https://github.com/justlayme/unbubble#readme) for the current product and [iPhone source](https://github.com/justlayme/unbubble/tree/main/ios) for app development.
